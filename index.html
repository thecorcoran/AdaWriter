Hardware & Software Project

AdaWriter

A dedicated, distraction-free writing appliance built on Raspberry Pi and E-Paper.

Quick Start Guide Hardware Specs GitHub Repo

Overview

AdaWriter transforms a Raspberry Pi Zero 2 W and a Waveshare 4.2-inch e-paper display into a quiet, dedicated digital typewriter. Designed to foster deep contemplative writing and journaling without browser tabs, notifications, or battery anxiety.

Key Features

📜

Distraction-Free E-Ink

Crisp typography with full refreshes on menu transitions and rapid partial refreshes while typing for low-latency response.

📅

Automated Journaling

Daily auto-created journal entries stamped with timestamps and automatically compiled into cumulative monthly archives.

📁

Multi-Project Workspaces

Dedicated slots for major project drafts with built-in renaming, archiving, and deletion safeguards.

📶

Wi-Fi File Transfer

Built-in lightweight HTTP server allows browsing and downloading documents (.txt and .doc/RTF) over local Wi-Fi.

⌨️

Auto Keyboard Detection

Direct low-level evdev input handling that automatically binds to any connected USB keyboard.

⚡

Safe Power Management

Inactivity shutdown timer and graceful power-off sequence featuring custom art and literary quotes.

Software & Setup

1

Enable SPI on Raspberry Pi OS

Run sudo raspi-config, navigate to Interface Options → SPI, and select Yes.

2

Install System Dependencies

sudo apt update && sudo apt install -y python3-pip python3-venv git network-manager fonts-pt-serif fonts-dejavu-core
3

Install Python Libraries

pip install pygame evdev Pillow netifaces waveshare-epd
4

Run as Appliance Service

Configure systemd to launch AdaWriter on boot:

sudo systemctl enable adawriter.service
sudo systemctl start adawriter.service
